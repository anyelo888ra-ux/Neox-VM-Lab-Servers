# NEOX Server Web Lab Commands

The first web simulator intentionally exposes a small allowlist of commands.

| Command | Function |
|---|---|
| help | List available commands |
| status | Show simulated server status |
| services | Show simulated services |
| uptime | Show laboratory uptime |
| version | Show Web Lab version |
| clear | Clear terminal |

The Web Lab must not execute arbitrary host shell commands from browser input.
